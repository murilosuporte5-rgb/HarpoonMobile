# HarpoonLab V0.13

Independent telemetry lab. It does not automate gameplay or execute remote code. The existing fish.lua remains unchanged.

Run `cd lab && lua5.4 test_core.lua` to reproduce the 27 core tests. The tested code uses the common Lua/Luau syntax subset; execution in the Roblox runtime has not been validated. Evidence is provided by a caller, not independently verified by the core.

The separate downloadable package also contains the Python offline report analyzer and its 23 tests.
